# Koydo Open Curriculum

This repository is a public placeholder for Koydo's open curriculum principles.

Koydo is exploring curriculum infrastructure that helps organize learning goals, skills, prerequisites, practice, assessment, and multilingual learning paths in ways that are easier to inspect, adapt, and use.

This repository does not contain production code or full curriculum datasets. It contains public-safe principles and documentation only.

## Goals

- Make curriculum structure easier to understand.
- Support learning across languages and local contexts.
- Keep learning goals, skills, and prerequisites explicit.
- Encourage reusable, inspectable curriculum organization.
- Leave room for educator, family, and partner judgment.

## Current Status

This is an early public information repository. Additional public documentation may be added as Koydo's open curriculum work matures.
