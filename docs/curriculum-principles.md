# Curriculum Principles

Koydo's open curriculum work is guided by these public principles.

## Start With Learning Goals

A curriculum system should make learning goals explicit before adding activities, assessments, or technology.

## Show Prerequisites

Learners and educators should be able to see what knowledge or skills a topic depends on.

## Support Practice

Curriculum infrastructure should connect goals to practice, feedback, review, and mastery over time.

## Respect Context

Learning systems should adapt to language, age, culture, exam requirements, classroom setting, family needs, and local constraints.

## Stay Inspectable

Educators, families, partners, and reviewers should be able to understand how learning paths are organized.

## Use AI Carefully

AI can help generate explanations, examples, practice, and feedback, but curriculum decisions should remain understandable and reviewable.
