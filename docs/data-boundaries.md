# Data Boundaries

This public repository does not include learner records, private analytics, production datasets, private curriculum partner materials, or unreleased product data.

Future public curriculum artifacts should be reviewed before publication to ensure they do not include:

- personal information
- learner records
- private assessment content
- confidential partner materials
- internal product configuration
- provider IDs, secrets, or operational metadata

Public curriculum documentation should be safe for families, schools, partners, and reviewers.
